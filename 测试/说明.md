# 测试

在本机跑通过的实测流程。都要先装好赫朝启动器的企划导入工具和客户端探针（默认在 `~/cc/黑箱Boss/启动器`，别处用 `HECHAO_LAUNCHER` 指过去）。这两样原来不在任何仓库里，2026-11-17 把源码拷了一份到 `测试/工具/`，新电脑怎么装见 [交接.md](../交接.md) 第四节。

1. 构建：先 `源码/血肉公园插件`，再 `源码/客户端模组`，都是 `./gradlew --offline build`。
2. `测试/装进启动器.sh`：把两个 jar 拷进 `交付/` 和启动器的血肉公园实例，最后一行是“检查通过”才算装好。
3. `测试/实测.sh <步骤文件> <截图目录>`：开一个藏在后台的测试客户端进测试服，按步骤走、截图。客户端缓存在 `FLESHPARK_WORK`（默认 `~/.cache/fleshpark-test`）。

`启动器清单.json` 是导入工具读的企划清单（端口、jar 名、Modrinth 模组）。

## 步骤文件

每行一条，`驱动.py` 开头有完整说明：

- `c shot 名字` 截图，`c cmd 命令` 发命令（不带 /），`c lookat x y z`、`c look 水平 俯仰`、`c use` 右键。
- `g x z [秒]` 走到某处。
- `w 秒` 等。
- `l 文字 秒` 等服务端日志出现这段文字（剧情里打的日志，比如“磁带 放进录音机”“807 发车”）。

`步骤/深井跑酷全程.txt` 是第四关的整段实跳：从电梯一处处跳到平台（蹲着钻肉箍、连按左键扯肉索、连按空格拔脚），扔冷光棒、坐 807 号车到底，一路开着 `meshstat` 记帧数。这份是插件自检生成的（`build/well-parkour-test.txt`），改了落脚处重新构建插件再拷过来。`h x z` 是跳着走（探针的 `hop`：走到边上脚前面空了就起跳），`k 高度` 是检查点（人已经被接到更下面了就跳过前面几处）。想看着测加 `FLESHPARK_SHOW=1`：窗口拉到前台、放大、开一半音量（`FLESHPARK_VOLUME` 可改）。`c jump`、`c front`、`c volume`、`hop` 都是 2026-11-15 给客户端探针加的，旧的探针 jar 不认。贴井壁的那几处，机器人先走到起跳点往回 1.6 格（`g`），再顺着走向助跑跳到下一处正前方空得最少的那一格，和真人走到头再跳一样。`步骤/深井楼梯近景.txt` 站在九截断楼梯的落脚点上顺着楼梯往前拍一张、从下一处回头拍一张（开着手电，`c hud off` 先把界面藏起来；这条也是 2026-11-15 加的）。`步骤/肉箍复现.txt` 照真人的几种走法钻肉箍（站着撞上、按住蹲走三条线、在底下等它喘气）；`步骤/跳关和807复测.txt` 用 `/fp tp` 跳到 4 号支撑和 807 号车，从半空掉一次看接不接得住，坐车滑到一半按蹲键。`步骤/收尾.txt` 从导演栏"收尾"进去：看水里的对讲机、点它（点不中就 `/fp walkie` 直接放），录音放完接广播、发疯、手变灰、手机收两条短信、视野撑开、变红、掐断、片尾，一路截图。`步骤/收尾回放.txt` 跳到收尾点对讲机，按每句开始的时间截头盔录像回放的 14 张（下楼、背影、脸、一排排、抬头、低头看水、楼梯、小罗坐下、转过来、矮下去、回到现在）。`步骤/运送单和收尾.txt` 看接驳车司机隔间背后的运送单（0.5.5 改的，还没前台看过）再跳收尾。`步骤/深井近景.txt` 传送到深井三张新纸条跟前读出来，再拍断楼梯的小灯、风管头顶的喷漆字、灯箱、从平台往下看；纸的位置抄自插件构建出的 `build/notes-test.txt`，改了落脚处要重拷。

`步骤/0.5.0全程.txt` 是 0.5.0 实测用的全程，从开场走到片尾。车站上车要走 x=-4.0，别贴着门缝走；车站门要先读完纸条或 `fp unlock`。

测试客户端每次启动，导入工具都会把 `options.txt` 重写一遍、主音量设成 0（测试不吵人）。要测音量，在步骤里用 `c cmd fp fx audio slider 滑块 值` 改，再用 `c cmd fp audio` 把每个频道的读数写进客户端日志（`session/血肉公园/game/logs/latest.log`）。
